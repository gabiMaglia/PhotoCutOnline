PhotoCut Studio

PhotoCut Studio lo desarrolla y mantiene una sola persona, así que cada mensaje se lee de verdad. Si encontraste un error, tenés una idea para una función nueva, una duda sobre cómo funciona el recorte o simplemente querés dejar tu opinión, escribí a:

gab.maglia@gmail.com

Algunos datos que ayudan si reportás un problema: el navegador y sistema operativo que usás, qué botón o herramienta estabas usando (Recorte IA, recuadro, pinceles, Icon Studio) y, si podés, una captura de pantalla. Como ninguna imagen se sube a un servidor, nunca vamos a poder ver tu foto del lado nuestro — si hace falta, podés adjuntarla vos mismo al correo.
