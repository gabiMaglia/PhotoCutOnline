Cómo elegir una paleta de colores (para una web, marca o diseño)

Actualizado: julio de 2026 · Lectura: 7 minutos · Por Gabriel Maglia

Elegir colores «a ojo» es la forma más rápida de que un diseño se vea amateur. Una buena paleta no es una lista de colores lindos: es un sistema —unos pocos colores con roles claros y sus variantes— que hace que todo lo que armes se vea coherente. Esta guía te muestra cómo definir una paleta que funcione, cómo derivarla de una imagen que te guste y cómo dejarla lista para tu proyecto.

El error más común: demasiados colores sin rol

Mucha gente junta 8 o 10 colores que le gustan y los usa sin criterio. El resultado es ruido. Una paleta profesional se organiza por roles, no por gustos:

  • Primario: el color de tu marca, el que más se repite (botones, enlaces, acentos).
  • Secundario / acento: uno o dos colores de apoyo para destacar cosas puntuales.
  • Neutro: una escala de grises para fondos, bordes y texto. Es el que más se usa, aunque no lo parezca.
  • Estado: éxito (verde), advertencia (ámbar), error (rojo), info (azul). Convenciones que el usuario ya entiende.

De dónde sacar los colores

No hace falta inventar de cero. Las mejores paletas suelen derivar de una referencia: una foto, una obra de arte, un producto, un paisaje. Si ya tenés una imagen cuya combinación te encanta, extraé sus colores dominantes con un extractor de paleta: subís la imagen y obtenés los HEX exactos. A partir de ahí, asignás roles.

Paso a paso

  1. Elegí una referencia cuya combinación de colores te guste.
  2. Extraé sus colores dominantes con su HEX.
  3. Asigná roles: primario, secundario, neutro y estados.
  4. Generá una escala de cada color (claro a oscuro).
  5. Exportá a variables CSS o Tailwind para usarla de forma consistente.

Las escalas 50–900: el truco de los sistemas de diseño

Un color no alcanza con una sola versión. Necesitás el primario claro para un fondo suave, medio para un botón, oscuro para el texto sobre claro. Por eso los sistemas de diseño (Material, Tailwind) usan escalas: del 50 (casi blanco) al 900 (casi negro), conservando el tono. Con una escala por rol tenés todas las variantes que vas a necesitar sin improvisar. La herramienta de Color Studio puede generar estas escalas —y los tokens semánticos— y copiarlas como CSS o Tailwind listas para pegar.

Reglas rápidas de armonía

  • 60-30-10: ~60% de un color dominante (casi siempre el neutro), 30% del secundario y 10% del acento. Evita que todo compita.
  • Contraste para el texto: el texto tiene que leerse. Apuntá a un contraste alto entre texto y fondo (revisalo con un verificador de contraste).
  • Un solo acento fuerte: si todo grita, nada resalta. Reservá el color más saturado para lo importante.

No te olvides de la accesibilidad

Una paleta linda que no se entiende no sirve. Dos chequeos rápidos: contraste suficiente entre texto y fondo, y que la información no dependa solo del color (cerca del 8% de los hombres tiene daltonismo). Podés simular cómo se ve tu diseño con daltonismo para asegurarte.

Preguntas frecuentes

¿Cuántos colores debería tener una paleta?

Un primario, uno o dos secundarios/acento, un neutro (grises) y colores de estado. Con 3 a 5 colores base y sus variantes alcanza para casi todo.

¿Cómo saco una paleta de una imagen?

Con un extractor de paleta: subís la imagen y obtenés los colores dominantes con su HEX.

¿Qué es una escala de color (50 a 900)?

Variantes de un mismo color, del más claro (50) al más oscuro (900), conservando el tono. El estándar en sistemas de diseño.

¿La paleta funciona para personas con daltonismo?

Conviene revisarlo: si la información depende solo del color, parte de tus usuarios no la distingue. Simulá el daltonismo y cuidá el contraste.

Lo probamos: de una foto a una paleta usable

Cargamos una foto y Color Studio extrajo una paleta de 6 colores (ajustable). El cuentagotas muestra el HEX exacto al pasar el mouse por la imagen, y con un clic lo fijás y copiás.

Lo práctico para diseño y web: además de copiar los HEX, exporta la paleta como variables CSS o JSON, lista para pegar en un proyecto. Sin registro y sin subir la imagen.
