Por que fiz o PhotoCut Studio

O PhotoCut Studio nasceu de um incômodo concreto: quase todos os editores de recorte «grátis» enviam sua foto para um servidor externo, processam-na lá e, depois de alguns usos, pedem para você pagar ou criar uma conta. Eu quis o contrário: uma ferramenta que roda inteiramente dentro do navegador, onde a imagem nunca sai do seu dispositivo. O recorte automático usa um modelo de IA (u2netp, 4,6 MB, licença Apache-2.0) exportado para ONNX que roda via WebAssembly em um Web Worker; o recorte interativo se apoia no GrabCut compilado para WASM. Não há backend que receba suas fotos porque, simplesmente, não há para onde enviá-las.

Como escrevo estes guias

Não escrevo sobre recursos que não testei. Cada guia deste site eu executo no próprio editor — carrego uma imagem real, sigo os passos e capturo a tela dessa mesma sessão — antes de publicá-lo. Quando um guia diz que o PNG exportado fica com o fundo 100% transparente, é porque abri o arquivo e verifiquei o canal alfa. O bloco «Nós testamos» que você verá em cada um resume o que realmente aconteceu na prática, incluindo os casos em que o resultado automático precisou de alguns retoques. Esse é o critério: contar o que de fato acontece ao usar a ferramenta, não uma versão idealizada.
