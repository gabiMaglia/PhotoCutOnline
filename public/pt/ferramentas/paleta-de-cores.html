O que você pode fazer

  • Extrair a paleta dominante: as cores mais representativas da imagem, ordenadas, com o HEX.
  • Escolher quantas cores: de 3 a 12, para uma paleta mínima ou mais detalhada.
  • Conta-gotas (color picker): passe o mouse sobre a imagem e leia o HEX exato em qualquer ponto; clique para fixar e copiar.
  • Copiar para o seu código: a paleta como HEX, como variáveis CSS ou como JSON.

Para que serve uma paleta de cores

  • Web & UI: derivar as cores de uma marca ou de uma foto de referência e colar como variáveis CSS.
  • Branding: documentar as cores exatas de um logo ou identidade visual.
  • Slides e redes: montar gráficos que combinem com uma imagem principal.
  • Arte e ilustração: estudar a paleta de uma obra ou foto que inspira você.

HEX, RGB e por que importa o código exato

Uma cor na tela é identificada por um código: o HEX (por exemplo #d6f64b) é o mais usado em web design porque é curto e universal. «Mais ou menos aquele verde» não basta quando dois elementos precisam combinar — você precisa do código exato. O conta-gotas dá exatamente isso: o HEX do pixel que você escolher, sem adivinhar.

Privado por design

Ao contrário de muitas ferramentas online que enviam sua imagem a um servidor, aqui a análise de cor roda inteiramente no seu navegador. Sua imagem não viaja a lugar nenhum — ideal para material de clientes, designs não publicados ou qualquer coisa que prefira manter privada.

Perguntas frequentes

Como pego o código HEX de uma cor de uma imagem?

Abra a imagem na ferramenta de Cores e passe o mouse por cima: aparece o HEX do pixel sob o cursor. Clique para fixar e copiar.

Como funciona a extração da paleta?

Agrupa pixels parecidos com um algoritmo de quantização (median-cut) e retorna as cores dominantes mais representativas, de 3 a 12.

Posso exportar a paleta para usar em código?

Sim: como HEX, como variáveis CSS (:root { --color-1: … }) ou como array JSON.

Minha imagem é enviada a um servidor?

Não. Toda a análise roda no seu navegador; a imagem nunca é enviada nem armazenada.
