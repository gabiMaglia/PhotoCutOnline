Como escolher uma paleta de cores (para site, marca ou design)

Atualizado: julho de 2026 · Leitura: 7 minutos · Por Gabriel Maglia

Escolher cores "no olho" é a forma mais rápida de um design parecer amador. Uma boa paleta não é uma lista de cores bonitas: é um sistema —poucas cores com papéis claros e suas variantes— que faz tudo o que você monta parecer coerente. Este guia mostra como definir uma paleta que funciona, como derivá-la de uma imagem que você curte, e como deixá-la pronta para o seu projeto.

O erro mais comum: cores demais sem papel

Muita gente junta 8 ou 10 cores que gosta e usa sem critério. O resultado é ruído. Uma paleta profissional se organiza por papéis, não por gostos:

  • Primária: a cor da sua marca, a que mais se repete (botões, links, acentos).
  • Secundária / acento: uma ou duas cores de apoio para destacar coisas pontuais.
  • Neutra: uma escala de cinzas para fundos, bordas e texto. É a mais usada, mesmo que não pareça.
  • Estado: sucesso (verde), aviso (âmbar), erro (vermelho), info (azul). Convenções que o usuário já entende.

De onde tirar as cores

Não precisa inventar do zero. As melhores paletas costumam derivar de uma referência: uma foto, uma obra de arte, um produto, uma paisagem. Se você já tem uma imagem cuja combinação adora, extraia suas cores dominantes com um extrator de paleta: você envia a imagem e recebe os HEX exatos. A partir daí, atribui papéis.

Passo a passo

  1. Escolha uma referência cuja combinação de cores você gosta.
  2. Extraia suas cores dominantes com o HEX.
  3. Atribua papéis: primária, secundária, neutra e estados.
  4. Gere uma escala de cada cor (claro a escuro).
  5. Exporte para variáveis CSS ou Tailwind para usar de forma consistente.

As escalas 50–900: o truque dos design systems

Uma versão de uma cor não basta. Você precisa da primária clara para um fundo suave, média para um botão, escura para texto sobre claro. Por isso os design systems (Material, Tailwind) usam escalas: do 50 (quase branco) ao 900 (quase preto), mantendo o tom. Com uma escala por papel você tem todas as variantes de que vai precisar sem improvisar. O Color Studio pode gerar essas escalas —e os tokens semânticos— e copiá-las como CSS ou Tailwind, prontas para colar.

Regras rápidas de harmonia

  • 60-30-10: ~60% de uma cor dominante (quase sempre a neutra), 30% da secundária e 10% do acento. Evita que tudo compita.
  • Contraste para o texto: o texto tem que ser legível. Mire um contraste alto entre texto e fundo (confira com um verificador de contraste).
  • Um único acento forte: se tudo grita, nada se destaca. Reserve a cor mais saturada para o que importa.

Não esqueça a acessibilidade

Uma paleta bonita que não se entende não serve. Dois checks rápidos: contraste suficiente entre texto e fundo, e que a informação não dependa só da cor (cerca de 8% dos homens tem daltonismo). Vale simular como seu design aparece com daltonismo para se certificar.

Perguntas frequentes

Quantas cores uma paleta deve ter?

Uma primária, uma ou duas secundárias/acento, uma neutra (cinzas) e cores de estado. Com 3 a 5 cores base e suas variantes dá para cobrir quase tudo.

Nós testamos: de uma foto a 6 HEX, a variáveis CSS, e o conta-gotas contra cores conhecidas

Imagem: quitar-fondo-antes.jpg, 720 × 900 px, 78,4 KB (retrato de domínio público).

Ferramenta: Color Studio → Paleta.

O que eu fiz:

  1. Carreguei o retrato com «Abrir foto» e fui ao «Color Studio» (paleta de 6 cores por padrão).
  2. Movi «Quantidade de cores» para 3, para 12 e de volta para 6; apertei «Copiar variáveis CSS» e «Copiar JSON» e li a área de transferência.
  3. Carreguei captura-ui-clara.png (1280 × 720 px, 41 KB), uma captura desenhada por mim com cores chapadas conhecidas, e fixei com clique o conta-gotas sobre quatro zonas.

O que eu medi:

  • Ao entrar no Color Studio a paleta de 6 apareceu em 0,47 s. Mudar para 3 cores levou 170 ms e para 12, 183 ms.
  • Paleta de 6: #0d121f, #34212b, #66423a, #a95444, #807c87, #d3b5a8. Com 3: #211925, #874b3f, #aa9898.
  • «Copiar variáveis CSS» deixou 8 linhas na área de transferência (a primeira: «:root {»). «Copiar JSON» é um JSON válido.
  • Conta-gotas sobre cores chapadas conhecidas: 4 de 4 HEX coincidiram exatamente (#F5F7FA → #f5f7fa; #2563EB → #2563eb; #DC2626 → #dc2626; #16A34A → #16a34a).

O que deu errado ou que limite eu vi: As paletas de 3 e de 6 cores não são uma subparte da outra (a primeira cor das 3 não está entre as 6): mudar a quantidade recalcula e pode mudar cores. O conta-gotas só verifiquei sobre cores chapadas; numa foto com ruído depende do pixel exato onde cai o clique.
