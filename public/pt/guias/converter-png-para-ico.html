Converter PNG para ICO grátis: favicon e ícone do Windows

Atualizado: julho de 2026 · Leitura: 5 minutos

O formato ICO continua sendo, uns vinte e tantos anos após sua criação, o que o Windows pede como ícone de um executável e o que muitos navegadores buscam por padrão em /favicon.ico. A particularidade do ICO é que ele não é uma única imagem: é um contêiner que agrupa várias resoluções (16, 32, 256 px…) dentro do mesmo arquivo, e o sistema escolhe a de que precisa conforme onde é exibido. Converter um PNG normal para esse formato exige uma ferramenta que monte essa estrutura corretamente — não basta trocar a extensão do arquivo.

Por que não basta renomear o arquivo

Um erro frequente é pegar um logo.png e salvá-lo como logo.ico esperando que funcione. Não funciona: um ICO real tem um cabeçalho binário (ICONDIR) que descreve quantas imagens contém e em que resolução, seguido dos dados de cada uma. Sem essa estrutura, o Windows e os navegadores não reconhecem o arquivo como um ícone válido, mesmo que a extensão diga .ico.

Como converter um PNG para ICO, passo a passo

  1. Abra o PhotoCut Studio e entre na seção Icon Studio.
  2. Envie seu PNG de origem, idealmente quadrado e de 512 px ou mais, sem compressão.
  3. Escolha o set do Windows: gera um app.ico com as resoluções 16, 24, 32, 48, 64, 128 e 256 px embutidas em um único arquivo.
  4. Revise a prévia nos tamanhos pequenos (16 e 32 px) para confirmar que o ícone continua reconhecível.
  5. Baixe o arquivo .ico e use como favicon (favicon.ico) ou como ícone do executável do seu app de Windows.

Usar o ICO como favicon

Para o navegador, basta enviar o favicon.ico para a raiz do site (ou onde seu servidor apontar) e, opcionalmente, declará-lo no HTML:

<link rel="icon" href="/favicon.ico" sizes="48x48">

Muitos navegadores e crawlers pedem /favicon.ico diretamente mesmo sem estar declarado no HTML, então vale sempre tê-lo na raiz do domínio como reserva, mesmo que seu favicon principal seja um PNG ou SVG mais moderno.

Usar o ICO num app de desktop para Windows

Se você está empacotando um aplicativo de desktop (com Electron, Tauri, .NET ou qualquer outro stack), o instalador e o executável pedem um .ico multirresolução para mostrar no Explorador de Arquivos, na barra de tarefas e nos atalhos. É aí que mais se nota se o ICO tem poucas resoluções: um ícone que só inclui 256 px fica borrado ao ser reduzido para a barra de tarefas (normalmente 32 ou 16 px), enquanto um com as sete resoluções padrão fica nítido em qualquer contexto.

Erros comuns ao converter PNG para ICO

  • Incluir uma só resolução. Um ICO com só 256 px obriga o sistema a reescalar para os tamanhos pequenos, perdendo nitidez. Inclua sempre o set completo (16 a 256 px).
  • Partir de um PNG com pouca margem. A 16 px o detalhe fino some; se a arte chega bem na borda do canvas, é recortada visualmente ao aparecer tão pequena.
  • Transparência mal tratada. O ICO admite transparência (diferente do BMP clássico), mas vale revisar a prévia: alguns visualizadores antigos do Windows mostram um fundo cinza em vez de transparente.
  • Confundir ICO com favicon PNG. Hoje o favicon "moderno" costuma ser um PNG de 32 px declarado no HTML; o ICO continua necessário como reserva universal e para o Windows, mas não substitui o resto do set de ícones web.

Perguntas frequentes

O que é exatamente um arquivo ICO?

Um ICO é um contêiner que agrupa várias imagens de resoluções diferentes (por exemplo 16, 32 e 256 px) em um único arquivo. O sistema operacional ou o navegador escolhe automaticamente a resolução de que precisa conforme onde o ícone é exibido.

Posso converter qualquer PNG para ICO ou tem que ser quadrado?

Tecnicamente dá para converter qualquer PNG, mas o resultado fica melhor se o original for quadrado: se não for, o conversor o encaixa dentro de um quadrado e pode adicionar margens ou cortar as bordas mais longas.

Qual a diferença entre o ICO para favicon e o ICO para um .exe do Windows?

Nenhuma no nível de formato: é o mesmo tipo de arquivo ICO com resoluções embutidas. A diferença é onde você usa — o navegador o lê como favicon, e o Windows o lê como ícone do executável.

Renomear um PNG para .ico funciona?

Não. Um ICO real tem um cabeçalho binário (ICONDIR) que descreve quantas imagens contém e em que resolução. Sem essa estrutura, o Windows e os navegadores não reconhecem o arquivo como um ícone válido, mesmo que a extensão diga .ico.
