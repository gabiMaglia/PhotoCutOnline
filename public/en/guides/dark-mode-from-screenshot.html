Generate the dark mode (or light) of a screenshot

Updated: July 2026 · Reading time: 5 minutes · By Gabriel Maglia

Want to see how your app or website would look in dark mode without touching a line of code? A screenshot is enough. Color Studio can invert the image's lightness while keeping the colors —the real basis of dark mode— and give you the dark (or light) version instantly, with a before/after to compare. All free and in your browser: the screenshot isn't uploaded anywhere.

How the Theme mode works

It's not a simple "negative" of the photo. Inverting the colors outright turns blues orange and everything looks wrong. The Theme mode inverts only the lightness of each pixel and keeps the hue and the saturation: that's why a white background becomes dark, black text lightens, and a blue button stays blue (in my test, #2563eb became #0744cb: darker, not lighter). It's exactly what a good dark theme does.

Step by step

  1. Go to Color Studio and open the screenshot (or use the image you already have loaded).
  2. Choose the Theme mode and the target: Dark, Light or Invert.
  3. Compare the original with the generated version in the Before and After panels.
  4. Download the result as PNG.

The Dark and Light targets only invert if needed (depending on whether the screenshot is already light or dark); Invert always forces the change.

We tested it: from a light screenshot to a dark theme

We loaded a screenshot and the Dark mode inverted the lightness keeping the colors (with an option to keep the accents), showing before/after side by side. With UI screenshots it gives a realistic starting point; with regular photos, an artistic effect.

The most useful part for development: besides the image, it generates the derived color scheme (50–900 scales) ready to copy as CSS or Tailwind and paste into the project. All local, without uploading the screenshot.

Test run by the PhotoCut Studio team using the web version in Chrome. The screenshot above is from that session.

The project's color scheme

Below the before/after, Color Studio builds the color scheme derived from the image (50–900 scales per role) and leaves it ready to copy as CSS or Tailwind. It's useful for going from the mockup to real variables without picking the colors by hand out of the screenshot.

What it's for (and what it isn't)

  • Yes: quick dark-mode mockups, exploring palettes, pieces for presentations, seeing how an interface "breathes" in dark before coding it.
  • Yes, fun: throwing in any photos to see artistic and unexpected results.
  • No: it doesn't replace implementing the real dark theme in your CSS —an image is not an interface—, but it's the fastest way to visualize the idea.

It works best with UI screenshots

The "flatter" and more UI-like the image (an app, a site, a dashboard), the better it looks: solid backgrounds and text respond perfectly to the lightness inversion. Photographs with gradients and skin give a more artistic than utilitarian result — but trying them is part of the fun.
