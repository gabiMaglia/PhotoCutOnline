Contact

PhotoCut Studio

PhotoCut Studio is built and maintained by a single person, so every message is actually read. If you found a bug, have an idea for a new feature, a question about how the cutout works, or simply want to share your feedback, write to:

gab.maglia@gmail.com

A few details that help if you report a problem: the browser and operating system you use, which button or tool you were using (AI Cutout, box, brushes, Icon Studio) and, if you can, a screenshot. Since no image is uploaded to a server, we can never see your photo on our side — if needed, you can attach it yourself to the email.
